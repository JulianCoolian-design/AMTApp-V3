# ✈️ Airline Tycoon – Routen-Planer (AM4)

Streamlit-App, die für eine Route die optimale Flugzeug-Kombination zur Nachfrage findet
(Airline Manager 4). Die Nachfrage-Eingaben werden vor der Berechnung auf eine gerade Zahl abgerundet.

## Lokal starten

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Auf Streamlit Community Cloud deployen

1. Diesen Ordner-Inhalt in ein GitHub-Repository hochladen (`app.py`, `requirements.txt`, `.streamlit/config.toml` müssen im Repo liegen).
2. Auf https://share.streamlit.io mit GitHub anmelden.
3. **Create app** → Repository, Branch (`main`) und Main file path `app.py` wählen.
4. **Deploy** klicken. Fertig.
